# Prompt engine

PhotoCue composes assignments locally from independent subject, action, approach, purpose, detail, contrast, reflection, ethics, difficulty, and working-time vocabularies. A private installation seed, spin, mode, location, secure random value, and attempt counter determine selection. Fingerprints represent meaningful components rather than rendered wording; recent history rejects an exact component set.

Location text is neutral context only. It is bounded and stripped of control and HTML-delimiter characters. The engine never adds demographic, economic, safety, or political claims. Contributors should expand modular vocabulary—not lists of complete assignments—and keep fragments grammatically compatible.
